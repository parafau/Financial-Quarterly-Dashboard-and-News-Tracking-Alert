# Quarterly Trends

A minimal web page that shows how an Indian listed company has been doing over its recent quarterly reports, explained in plain language for people who don't know how to read company data.

Type an NSE symbol, pick the parameters you care about, and each parameter is shown with a chart of its quarter-by-quarter trend. Hover over (or tap) a parameter name to see what it means and what its trend says about that company.

> This is Flow 1 (quarterly-report trends) of a final-year project on analysing Indian stock portfolios.

## Features

- **Symbol + parameter inputs only.**
- **Hover pop-up with two sections for all parameters**
  1. **What is this?** (open by default): the meaning of the parameter for any company.
  2. **Effect on the company:** the trend in numbers (for example "Going up: Rs 63,000 Cr to Rs 72,000 Cr over 5 quarters") and what that means for the company shown.
- **Plain-language explanations written by hand,** not generated by dynamically by a NLP or AI model, so they are consistent and can't invent facts.



`main.py` and `parameters.json` must stay in the same folder.

## Parameters

Amounts are in Rs crore. Quarters are the ones Yahoo Finance returns, which is about the last 5.

| Parameter | How it is obtained |
|---|---|
| Sales, Expenses, Operating Profit, Interest, Profit before tax, Net Profit, EPS | Straight from the quarterly income statement |
| OPM %, Tax % | Calculated from the income statement |
| ROE % (annualised) | Quarterly net profit x 4 / shareholders' equity |
| ROCE % (annualised) | Quarterly EBIT x 4 / (total assets - current liabilities) |
| Book Value / share | Shareholders' equity / shares outstanding |
| Price (qtr-end) | Last closing price on or before the quarter-end date |
| Market Cap | Quarter-end price x shares outstanding |
| P/E (annualised qtr EPS) | Quarter-end price / (quarterly EPS x 4), only when EPS is positive |
| Dividend Yield % | Dividends paid in the 365 days before quarter-end / quarter-end price |
| 52W High, 52W Low | Highest and lowest close in the 365 days before quarter-end |

**Trend wording:** the first quarter is compared with the latest. A change of more than 3% (or more than 1 percentage point for percentage parameters) is called "Going up" or "Going down"; anything smaller is "Roughly steady".

## Editing the wording

All text shown in the pop-ups lives in `parameters.json`, so you can change it without touching Python. Each parameter looks like this:

```json
"Sales": {
  "chart": "bar",
  "unit": "rs_cr",
  "meaning": "What the parameter means for any company.",
  "up": "Shown when the trend is rising. {co} is replaced by the company symbol.",
  "down": "Shown when the trend is falling.",
  "flat": "Shown when the trend is steady."
}
```

- `chart` is `"bar"` or `"line"`.
- `unit` is `"rs_cr"`, `"percent"` or `"number"`.
- The order in the file is the order in the parameter dropdown.

**Adding a new parameter:** add its entry to `parameters.json`, and add a column with exactly the same name in `build_metrics()` in `main.py`.

## Data source and limitations

- Data comes from Yahoo Finance through the `yfinance` library, and is cached for one hour.
- Yahoo returns only about the last 5 quarters, so the trend covers roughly one year.
- Row labels in Yahoo's statements vary by company. If a parameter can't be found, the page shows "Data not available for this company."
- Banks and other financial companies report differently, so some parameters (such as Sales or OPM %) may be blank or less meaningful for them.
- The hover pop-up needs a recent browser (Chrome 120+, Firefox 130+, Safari 17.2+) for its two sections to switch properly.

## Disclaimer

Built for learning and research. The explanations describe what the numbers mean in general and are not investment advice.

## Service Goal working: 
1. Takes your Portfolio list as input to give you live dashboard of Company's data of its quarterly report with the information about the displayed parameters in general and how its trend has affected the stock value. 
2. Tracks Company directly and indirectly related news using a model to check the news relevance score, alerting the user about the news irrespective of it being positive or negative to the stock value.
