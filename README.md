# Financial-Quarterly-Dashboard-and-News-Tracking-Alert
##Repo works in 2 ways: 
1)Takes your Portfolio list as input to give you live dashboard of Company's data of its quarterly report with the information about the displayed parameters in general and how its trend has affected the stock value. 
2)Tracks Company directly and indirectly related news using a model to check the news relevance score, alerting the user about the news irrespective of it being positive or negative to the stock value.
